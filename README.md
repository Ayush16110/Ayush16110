## 🚀 Featured Projects

### 1. [ClauseNexa](https://github.com/Ayush16110/Clausenexa)

An AI-powered legal contract analysis platform designed to simplify working with large legal documents through document processing, semantic retrieval, and contextual AI analysis.

**Engineering highlights**
- Modular backend architecture separating core APIs, document processing, and AI services.
- PDF uploads, document metadata management, and Cloudflare R2 object storage.
- Document versioning and processing-status tracking.
- Planned asynchronous processing with Redis and BullMQ, vector search, and RAG-based contract analysis.

**Tech stack:** Node.js · Express.js · MongoDB · Mongoose · Cloudflare R2

### 2. [Project Camp](https://github.com/Ayush16110/project-camp-backend)

A RESTful backend for collaborative project management, supporting project creation, team membership, and role-based access control.

**Engineering highlights**
- JWT authentication with access and refresh tokens.
- Email verification, password reset, and password hashing.
- Project creation, retrieval, updates, and deletion.
- Project membership management with role-based permissions.
- Request validation and reusable authentication and authorization middleware.

**Tech stack:** Node.js · Express.js · MongoDB · Mongoose · JWT · bcrypt

### 3. [Todo GUI](https://github.com/Ayush16110/todo-cpp-gui)

A desktop task management application built with C++ and Qt Widgets, evolving a command-line task manager into a graphical application.

**Engineering highlights**
- Create, edit, delete, and complete tasks.
- Persistent task storage using a local file.
- Separation of UI components and backend task-management logic.
- ID-based task operations and a backend-driven source of truth.
- CMake-based build configuration.

**Tech stack:** C++ · Qt Widgets · CMake
